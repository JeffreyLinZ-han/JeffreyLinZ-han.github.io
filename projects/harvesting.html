Berry Harvesting Robotics

The hardware geometry already existed. The challenge was turning it into a robot model that could actually move, collide, and become useful for manipulation research.

MuJoCoCAD/URDF100+ STL ComponentsMotion PlanningRobot Perception
Simulation

The CAD existed.
The robot did not.

I rebuilt the simulation pipeline from an existing hardware platform, where more than a hundred geometry assets had to stop behaving like disconnected meshes and start behaving like one mechanism. That meant fixing frames, mesh orientation, origins, hierarchy, and the structure hidden inside the CAD.

The result is a cleaner MuJoCo environment that can become the testbed for inverse kinematics and motion planning, then later perception, visual servoing, ROS 2 integration, and learning-based manipulation.
